# Цифровая карта исторических памятников Актюбинского края

Интерактивная карта 7 исторических памятников Актюбинской области и печатный постер A3 с QR-кодами.
Проект сделан по исследовательской работе «Цифровая карта исторических памятников Актюбинского края» (7 класс).

**Сайт:** https://kerejbajzakov-hue.github.io/maps-project/

## Как это работает

1. Постер A3 печатается и вешается в классе или коридоре.
2. Ученик наводит камеру телефона на QR-код рядом с памятником.
3. Открывается метка памятника: галерея фото (нажми — откроется на весь экран), район, дата или период, краткая историческая справка, координаты, ссылка на Visit Aktobe и вопрос «Проверь себя».

Структура метки и цвета взяты из раздела 4 работы: красный — мавзолеи и некрополи, синий — мемориальные комплексы, зелёный — археологические объекты, жёлтый — памятники и другие сооружения.

## Файлы

```
index.html                   сайт (одна страница, работает без сервера)
photos/                      фото памятников: <id>-1.jpg, <id>-2.jpg …
poster/poster-A3-photos.pdf  постер A3 с фото — для печати
poster/poster-A3.pdf         постер A3 с иллюстрациями
poster/poster-preview.png
poster/qr-codes-A4.pdf       отдельный лист QR-кодов
src/                         исходники: данные, иллюстрации, сборка сайта и постеров
```

Каждое фото открывается и по прямой ссылке, например
https://kerejbajzakov-hue.github.io/maps-project/photos/kyzyltam-1.jpg

## Как пересобрать

Нужны Python 3, Node.js с Playwright и шрифт Nunito, установленный в системе.

```bash
pip install -r src/requirements.txt
npm i playwright
./src/build.sh
```

- Тексты, координаты и ссылки памятников — `src/clay_common.py`, список `DATA`.
- Новое фото: положите в `photos/` с именем `<id>-<номер>.jpg` (id — как в `DATA`) и запустите `build.sh`.
- Подпись автора фото — словарь `CREDITS` в `src/build_app.py`.
- `BASE_URL` — адрес сайта, на который ведут QR-коды.
